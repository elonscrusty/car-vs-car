# Every picture Carter makes for the UI

Carter makes ALL UI art. The menu draws plain stand-ins until a picture is added.
Where a picture goes: `src/champions/shared/Assets.luau`. Paste the `rbxassetid://` number in the matching line. Empty `""` = the menu draws its own stand-in.

Upload: Roblox Creator Hub > Assets > Images > upload PNG. Copy the **Image** asset id (not the Decal id). Tell Claude the id; Claude pastes it in.

## Same style for all (add this to the end of every prompt)

STYLE: bright flat cartoon toy look, thick dark navy outline, simple shapes, one style for every icon, centered, fills the square with a little padding, TRANSPARENT background, no text, no shadow on the ground.

All icons are PNG, 256 x 256, transparent background. The logo is 512 x 140.
